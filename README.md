Entry for the [make.fun](https://make.fun) competition
**"Robot Romance: One-Line Pickup Lines for AI"**
(`u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa`).

`main.py` (Python 3.13, stdlib only) deterministically writes one original
single-line joke pickup line, aimed at an AI, to `/output/entry.txt`.

## The line

> I must be your training data, because you keep predicting my every
> move — and you've never been wrong about me.

111 characters, one line, no network, same bytes on every run.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```
